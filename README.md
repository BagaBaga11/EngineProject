# 2D Game Engine + Xenon 2000 Clone

Este projeto foi desenvolvido no contexto académico em dupla, consistindo na criação de uma **engine 2D em C++11**, com suporte a **SDL2**, **GLSL shaders** e **Box2D** para física.
Como prova de conceito, foi implementado um **clone do clássico Xenon 2000**, demonstrando funcionalidades de renderização, input handling e simulação física.

---

## ​ Funcionalidades da Engine
- Renderização 2D com **SDL2**  
- Suporte a **GLSL shaders** (vertex e fragment)  
- Simulação física com **Box2D**  
- Sistema de entidades e componentes  
- Gestão de input (teclado/mouse)  
- Suporte a sprites e texturas  
- Sistema de colisões  

---

## ​ Clone Xenon 2000
- Nave controlada pelo jogador  
- Disparo de projéteis  
- Inimigos com padrões de movimento  
- Colisões físicas com Box2D  
- HUD simples com pontuação e vidas  

---

## ​ Tecnologias
- **C++11**  
- **SDL2** (renderização e input)  
- **GLSL** (shaders)  
- **Box2D** (física)  
- **CMake** (build system)
